# Cinéphile Dashboard

A personal dashboard for film enthusiasts to track, rate, and reflect on the movies they watch. This React + Vite project features a sleek, modern interface inspired complete with mood-based color theming, film notes, ratings, and related film suggestions.

## Features

- Add, view, and edit films with:
  - Title, year, director, genres
  - Personal notes and rating (0-10)
  - Mood tagging (Cheerful, Playful, Introspective, Tense, Claustrophobic, Magical)
- View related films based on shared genres
- Responsive and visually engaging interface
- Mood-based color gradients for immersive experience
- Routing with React Router (`/`, `/add`, `/filmlist`, `/films/:id`)
- Deployed on GitHub Pages

## Technologies Used

- **React 18**
- **Vite** for build and development
- **Tailwind CSS** for styling
- **React Router DOM** for routing
- **Zustand** for state management
- **React Select** for dropdowns
- **React Hot Toast** for notifications
- **GitHub Pages** for deployment
